The ``1-my_list`` module
========================

Using ``MyList``
----------------

Import the class:

    >>> MyList = __import__('1-my_list').MyList

MyList is a subclass of list:

    >>> issubclass(MyList, list)
    True

Normal use:

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Empty list:

    >>> MyList().print_sorted()
    []

One element:

    >>> one = MyList([7])
    >>> one.print_sorted()
    [7]

Negative numbers:

    >>> neg = MyList([3, -1, 0, -5])
    >>> neg.print_sorted()
    [-5, -1, 0, 3]
    >>> neg
    [3, -1, 0, -5]

Already sorted and duplicate values:

    >>> MyList([1, 2, 2, 3]).print_sorted()
    [1, 2, 2, 3]

Reverse sorted:

    >>> MyList([5, 4, 3, 2, 1]).print_sorted()
    [1, 2, 3, 4, 5]

print_sorted returns None:

    >>> print(MyList([2, 1]).print_sorted())
    [1, 2]
    None
